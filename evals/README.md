# 评测集

目的：不靠总纲提醒，技能自己就能做出 85 分的页面（用户 2026-11-07：「我是希望你通过这个 skill，不通过这个 design MD，就能设计出 85 分的作品」）；分数一定要盲测（「你不能自己骗自己」）。

## 怎么评

- **题目**：从真实项目的页面类型里出（名单 + 详情、审核队列、向导、看板、设置、阅读、议程、手机下单……），每道题有固定数据和交互场景。一部分题只在发版时考，改技能时不看，免得练成只会做那几道。
- **每道题每边至少做两份**：只做一份量不出波动。
- **盲评**：两个不同的模型当评审，不知道谁是谁；成对比较，换一次左右顺序再评（防位置偏差，arXiv 2306.05685）。逐条判的清单是红线、总纲 §10 讨厌和机器检查，打分照总纲 §2.1。
- **金标准是用户自己**：用户挑的理由和原话写进总纲 §10、§11。
- **先校准，再用 AI 的分**（11-07：AI 75、用户 40，差 35）：请用户给几份页面盲打分（一个分 + 最差的一处），照用户的理由改评审清单，直到 AI 和用户差 ≤ 10 分。校准前 AI 评审只用来找问题，分数不当合格、不报给用户。
