# w · 照方法做了哪几步

1. 意图：内容策划，一天打开很多次，每次只想知道“哪个论坛还缺人、谁该催”，再顺手改状态、记一笔。要的感觉是会务排期表，密、安静，不像营销页。
2. 领域探索（四项）：领域 = 议程、分会场、席位、档期、邀请函、联络记录、确认出席；颜色世界 = 胸牌白、议程纸灰、确认绿、签到表墨、会场蓝。
   签名元素 = **席位条**：一个论坛计划几位就画几格，确认一位亮一格绿，在谈的是深灰。出现在 5 处：侧栏每一行、论坛页头、全部论坛总览（按论坛分组，点一组就切过去）、详情里的流程节点（同一套绿 / 进行中 / 灰）、名单状态圆点。
   拒绝的默认：一排 KPI 卡片 → 改成席位条；进度环 / 百分比 → 改成“确认几位 / 计划几位”；详情做成整页 → 改成右侧浮层。
3. 焦点：每一屏只有一个主角 = 当前论坛的标题 + 席位条（24/600 标题，下一行席位条 + 加粗确认数），其余降级：表头 13 灰、元数据列灰。
4. 密度：工作台式，行高 36，页头 24 内边距，各分区之间才拉开间距（侧栏全部 / 各论坛之间 12，详情各分区之间 32）。
5. 用已有的东西：全部用 @su 组件（Sidebar、NavItem、Table、Select、Drawer、Dialog、Field、Input、DatePicker、Segmented、Textarea、SearchField、Tooltip、EmptyState、Avatar），没有手写控件；颜色只用语义变量。
6. 自检：换皮测试（把席位条换成数字就退回模板，所以保留）；眯眼测试（标题和席位条最先看到，表格安静）；签名测试（上面 5 处）；变量测试（皮肤固定，没新增变量）。
7. 截图 4 轮：修了状态列基线偏下、详情抽屉不能滚、日志表单日期框太窄、保存按钮在折叠线以下、窄屏状态列看不到（把邀请状态挪到第二列）。

# 没照做的地方
- 方法要求先问用户、存 system.md：没人回答，所以写成假设；记录写在这里，没有建 system.md。
- 自定配色 / 字体 / 变量：皮肤固定用 Su，这部分只拿来查一致性。
- “进行中黄”：Su 没有黄色，warning 变量就是墨色；流程节点的“进行中”用 warning 色画的圈，没自己加黄色。
- 渲染方向样张（需要内联渲染工具）：没有这个工具，直接写代码再截图。

# 布局（5 行）
- 分区：左边侧栏 = 全部论坛 + 7 个分论坛（每行带席位条和“确认数/计划数”）；右边 = 页头（论坛名、席位条、日期·厅；搜索、新增嘉宾）+ 整张名单。
- 主次：当前论坛名 + 席位条是主角；名单表头吸顶、首列“演讲嘉宾”吸左，宽 128；邀请状态放第二列，用行内 Select 直接改；全部论坛时多显示“分论坛”一列。
- 详情：右侧 Drawer 浮在名单上（有遮罩和阴影，点空白 / Esc 收回）；顶部是 4 个节点的流程（能点），下面依次是基本信息、联络日志（“记一条”展开日期 / 方式 / 内容）、联系方式，字段名和表头同名，改了直接写回；底部切上一位 / 下一位。
- 渐进披露：日志表单点了才出现；新增用 Dialog，自动带上当前论坛和负责人（我）；搜索在当前范围里找名字或公司，当前论坛没找到、别的论坛有时，给一个按钮切到全部论坛。
- 动效：都用组件自带的弹簧（行增删、抽屉、弹层）；席位格只做底色过渡；日志表单用 Su 的 fast 时长做淡入加 4px 位移；状态改动弹一条 toast。
