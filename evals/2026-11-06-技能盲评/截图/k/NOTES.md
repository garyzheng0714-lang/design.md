# k · 演讲嘉宾工作台

## 做法
- 没有用任何设计方法或技能；只读了 Su 组件源码与 docs 示例（table、drawer、sidebar、nav-item、select、tag、field、date-picker、search-field）。
- 先读题目把 8 条功能逐条映射到组件，再写页面，截图迭代 3 轮（修了：抽屉打开时焦点环落到流程第一个节点；底部吸底的上一位 / 下一位被抽屉渐隐遮罩盖淡，改到标题下方；侧栏比例数字对不齐）。

## 布局（5 行）
1. 分区：左栏 Sidebar = 分论坛导航兼进度概览（第一行「全部论坛」是总进度，每行尾是 小进度条 + 已确认/计划）；右侧 = 标题区 + 名单。
2. 主次：当前论坛名做页面最大的字（30px，切换时上下换字），下面一行「已确认 3 / 7」+ 进度条 + 日期·会场；右上 SearchField 与唯一主按钮「新增嘉宾」。
3. 名单：Table 占满剩余高度、自己滚动，表头 sticky、首列「演讲嘉宾」sticky 且固定 144 宽；全部字段照原表叫法，显示全部不分页；「分论坛」列只在「全部论坛」视图出现；邀请状态格是 inline Select（触发器里放 Tag），就地改。
4. 渐进披露：详情用右侧 Drawer（浮在名单上方、有阴影、点空白收回）：上一位 / 下一位（也支持 ↑ ↓）→ 邀请流程节点（完成绿、进行中黄、未开始灰，可点）→ 基本信息 → 联络日志（「记一条」才展开日期 / 方式 / 内容）→ 联系方式。新增也是同一个抽屉，分论坛预填当前论坛。
5. 动效：进度条宽度、流程连线用 motion 弹簧（ui/ease 的 SPRINGS）；标题换字 popLayout；日志编辑器与新日志淡入；表格行增删、抽屉进出用组件自带动效。

## 没照做 / 取舍
- Su 的 warning 色是前景黑，题目要求「进行中黄」，流程节点的进行中用了一个局部琥珀色 oklch(0.84 0.15 85)；名单里「沟通中」仍用 Su 的 warning Tag（黑点）。
- 窄屏：侧栏收成抽屉（左上角按钮打开，里面有各论坛进度）；名单横向滚动、首列固定；搜索框落到进度下一行，新增变成图标按钮。
- 搜索只在当前视图（全部或当前论坛）里按名字 / 公司过滤。
- 所有场景都做了，S3 首屏即可见（步骤为空）。
