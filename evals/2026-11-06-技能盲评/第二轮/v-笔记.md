# 页面 v · 展商

## 做了哪几步
1. 读题目、数据和 HeroUI 技能与组件文档（Table、Tabs、Drawer、Modal、Popover、Calendar、Toast、SearchField、ToggleButtonGroup、ListBox）。
2. 先定这一屏只做一件事：每天反复打开，推进交付、找逾期。所以首屏就是「每个套餐的进度 + 按紧急程度排好的名单」，不加概览页。
3. 用数据算出派生值（下一个截止、逾期行、套餐进度），拆成 model / 名单 / 详情 / 日期 / 新增五个文件。
4. 1440 和 390 两个宽度逐个截图，改了：面板打开后表格折行、手机上逾期块被滑出屏外、j/k 切换后焦点框留在旧行、手机对接人一行挤不下。
5. 补拍创建、撤销、保存催办、键盘、窄屏逾期，确认都真的能用。

## 布局（5 行）
- 分区：顶部是标题、搜索和新增；下面一排进度块（全部、四个套餐、逾期）兼作筛选；再下面是名单。电脑上点一行，右侧推出 480 宽的详情，名单让位、不被遮住；手机上是列表加底部抽屉。
- 主次：名单默认按「下一个截止」排序，逾期的红字排最前；进度块只给数字和进度条；逾期块用红色分段，一段代表一项。
- 组件：进度块是 Tabs 加 ProgressBar；名单是 Table（可排序，表头吸顶），手机上用 ListBox；逾期视图是按权益列的 Table，带行内推进按钮；详情用 ScrollShadow、Avatar、Chip、Tooltip 加 Kbd；截止日是 Popover 加 Calendar；催办用 ToggleButtonGroup、TextArea 和日期按钮；新增用 Modal、TextField、Select、ToggleButtonGroup；反馈用 Toast。
- 渐进披露：详情只在点了以后才出现；催办编辑框点「记催办」才展开；截止日平时是一行字，点了才出日历；新增时选了套餐才带出权益清单和默认截止日；电话、微信、邮箱都是一键复制，数值放在提示里。
- 动效：详情面板用弹簧把宽度从 0 推到 480（0.45s、不回弹），退出 0.22s；上一家 / 下一家时内容沿方向错开 12px 淡入；状态图标切换时弹一下；新催办插进时间线；推进后弹 Toast，带「撤销」；跟着系统的减少动态设置。

## 场景说明
- 11 个场景都能做到。S5 用 `[data-advance="e03-3"]`，S6 用 `[data-due="e03-3"]`，S8 用 aria-label「下一家」（也可以按 j）。
- 开发服务器关了热更新，新建的页面文件进不了入口的页面列表（一开始 /v 显示「没有这个页面」）。我只 touch 了 `src/main.tsx` 的修改时间（内容 md5 前后一致），没有重启服务器，页面列表就刷新了。
