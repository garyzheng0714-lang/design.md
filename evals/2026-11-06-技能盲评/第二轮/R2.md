## 第二部分：30 条盲评（符合 / 不符合 / 不适用；8、22 不适用）

### A（致命不符合 2 条：6、13；得分率 79.7%）

不符合清单：
- 6（致命）：手写了状态字形的对勾与半圆，`parts/glyph.tsx` 的 `<path d="M5 8.2 7 10.2 11 6">` 加 `motion.circle`，名单每行一排用的 `Dot` 也是手画 SVG。另有注入式 `OpenRowStyle`（`roster.tsx`）。
- 13（致命，边缘）：`S9-新增-700.png` 的「公司」输入右缘比下方同组控件短（`create.tsx` 的 `pr-10`）。
- 4（重要）：名单底有「28 家」计数行（`page.tsx` 的 `count`），页标题「全部展商」与左栏条目同名。
- 19（重要）：详情里权益按数据顺序排，逾期的官网 logo 排第 4（`S4-开详情-700.png`）；默认名单也不按紧急度排。
- 25（重要）：关闭钮是灰底圆（`CloseButton`，`S4-开详情-700.png` 右上）。
- 30（重要，边缘）：窄屏左栏变成顶部下拉（`scopes.tsx` 的 `ScopeSelect`），控件形式和宽屏不一致；推进按钮要点行才长出，且没有可见提示。没有横向溢出、没有截断。

符合的重点：
- 1：没有说明句，占位符只有「搜索公司」「记一条催办…」。
- 3：没有任务外功能。
- 5：没有重复装饰；套餐视图里不再重复套餐列。
- 12：放大看图标与文字中线都对。
- 14：圆角没发现违例，未逐像素量。
- 21：弹簧 `bounce:0`，hover 不位移；`S3-切套餐-90.png` 没见到残影。
- 23：只有蓝加红。
- 24：线少，没有卡中卡（详情板是浮层）。
- 26：套餐默认取当前视图，方式默认电话，日期默认今天；新增没有「保存」键，边填边存。
- 27：表格有表头，6 列对齐（`1440.png`）。
- 28：字号 12 / 14 / 18 三级，没有指标卡。

打分：
- A 懵 8：第一眼是名单加左栏进度；小圆点图例要点时间才懂（5 / 8 配小圆点，靠数字兜底）。
- B 成熟度 7：很克制，hover 披露、方向滑动都像成熟产品；手画字形与新增表单略糙。
- C 少而精 8：常驻控件 2 个，次级操作全部延后。

结论：A 胜（致命 2 对 4）。

### B（致命不符合 4 条：1、3、6、23；得分率 59.4%）

不符合清单：
- 1（致命，边缘）：催办输入框占位符「催了什么，对方怎么回」（`Detail.tsx` 的 `Composer`）是字段说明句；另有空状态句「还没有催办记录」。
- 3（致命）：功能清单写明「就这些，不多做」，B 多做了：
  - 三列可排序（`Roster.tsx` 的 `allowsSorting`）。
  - J / K 切换与 `/` 聚焦搜索（`page.tsx` 的键盘监听）。
  - 推进后带「撤销」的 toast。
  - 点联系方式复制并弹 toast（`Detail.tsx` 的 `copy`）。
- 6（致命）：「逾期」方块里的 N 段红条是手写的 `<span className="h-1 flex-1 rounded-xs bg-danger">`（`page.tsx` 的 `OverdueTile`），是自造的进度图形。其余用的都是库里的。
- 23（致命）：蓝、红之外还有橙（待审核图标）、绿（已交付、「全部交付」）、琥珀（「还剩 7 天」）（`model.ts` 的 `warning-soft-foreground`、`Detail.tsx` 的 `STATUS_ICON`）。不是淡彩底，但不止「一个强调色加灰阶」。
- 2（重要）：搜索框里有 `/` 键帽；上一家 / 下一家的 tooltip 里有 `K`、`J` 键帽（`page.tsx`、`Detail.tsx` 的 `Kbd`）。
- 4（重要）：推进后弹「会刊整页广告 → 待审核」的 toast，复述已经看得见的变化（`S5-推进-90.png` 底部）；新增成功也弹 toast。
- 5（重要）：套餐视图里每一行仍带「金牌」灰标签（`S3-切套餐-700.png` 五行同一个标签），无信息量。
- 21（重要）：状态图标切换用了带回弹的弹簧 `bounce: 0.35`（`Detail.tsx` 的 `RightRow`），有过冲。
- 24（重要）：卡中卡较多：表格灰框里套白内卡、联系人灰卡、催办编辑区灰卡里再套文本框（`S7-记催办-700.png`）、表头竖分割线。
- 25（重要）：新增弹窗右上的关闭钮是灰底圆（`S9-新增-700.png`）。
- 26（重要，边缘）：新增套餐没有默认选中，必须选才能点「添加」；提交要多一步「添加」。
- 28（重要，边缘）：页头与表格之间插了一排 6 块同形方块，虽然兼作筛选，视觉上仍是「指标卡夹在中间」。

符合的重点：
- 7：点行开右侧板。
- 13：右缘对得齐。
- 19：权益按未交付优先、截止日升序（`sortRights`）；逾期表一行一项权益，推进就在行尾。
- 30：窄屏仍是 Tabs 方块，只是可横向滑，「逾期」提到第二位防被滑走（`page.tsx` 的 `VIEWS_NARROW`）。
- 12、14、15、16：没发现违例。

打分：
- A 懵 7：默认按紧急度排、逾期方块红条很醒目；但顶部 6 块方块加行尾按钮较多。
- B 成熟度 6：组件齐全；toast、键帽、彩色图标、灰标签、嵌套卡带 AI 感。
- C 少而精 5：多出排序、键盘、撤销、复制，常驻按钮多。

结论：B 负（致命 4 对 2）。

## 第四部分：取长补短

### A

最值得借的 3 处：
1. **视图即进度**：左栏每个套餐一条细进度加 `n / m`，「逾期」单列只给红字数（`scopes.tsx` 的 `ScopeLine`）。进入套餐视图后套餐列自动隐藏（`roster.tsx` 的 `showPkg`）。不另做指标卡，范围和进度一眼看到。
2. **权益推进的披露**：行尾推进按钮 hover 或聚焦才出现（`right-row.tsx`），触屏点行才长出；状态字换字滑动（`Swap`）；改完名单里那一排小圆点原位变（`S5-推进-90.png`）。次级操作延后，结果原位可见。
3. **新增 = 名单顶上长出一行 + 右侧边填边存**：换套餐时权益清单即时重新带出（`create.tsx` 加 `model.ts` 的 `applyPatch`），套餐默认取当前视图，没有「保存」键；还有「上一家 / 下一家」写出邻居名字并按方向滑动（`panel.tsx` 的 `Neighbors`）。

最该避免的 3 处：
1. 手画状态字形（`glyph.tsx` 的对勾和半圆）：12px 的半圆与虚线环辨识度低，要学图例；而且自造控件。
2. 新增表单：公司框 `pr-10` 右缘短 38px；5 个对接字段铺满抽屉；没有收尾按钮，底部还留着「禾川乳业 ›」邻居导航（`S9-新增-700.png`）；还没起名，左栏就已经变成 128 / 逾期 7（草稿把总数提前改了）。
3. 不按紧急度排：详情里逾期那项排第 4、默认名单不按截止日排；日期钮平时看不出可点；窄屏推进按钮要先点行才出现；多了「28 家」计数行；关闭钮灰圆底。

### B

最值得借的 3 处：
1. **逾期 = 权益表，默认按下一个截止升序**：`OverdueTable` 一行一项权益（权益 / 展商 / 截止日 / 状态 / 负责人 / 行尾推进），点行打开详情并让那一项闪红底淡出（`focusRight`）。第一眼就是最要紧的，且就地能处理。
2. **方块 Tabs 做套餐切换**：指示块滑动，每块内嵌进度条，逾期用 N 段红条；窄屏把「逾期」提到第二位（`VIEWS_NARROW`）。
3. **新增弹窗选套餐即时展开权益清单预览**（高度弹簧加列表淡入，`NewExhibitor.tsx`），把「权益清单自动带上」可视化；另有记催办点开才展开编辑区（`Esc` 取消）、权益行 `layout="position"` 重排。

最该避免的 3 处：
1. **每行常驻描边推进按钮**：详情里 6 个「收到物料」叠一列（`S4-开详情-700.png`），没有 hover 披露。
2. **任务外功能与复述**：`/` 和 J / K 键帽、撤销 toast、列排序、复制联系方式 toast、占位说明句「催了什么，对方怎么回」。
3. **多色与装饰**：橙 / 绿状态图标、琥珀字、每行灰 Chip 套餐；详情板用宽度动画推开表格，表格重排成省略号（`S4-开详情-90.png`，`page.tsx` 的 `motion.aside` `width`）；图标 `bounce: 0.35` 有过冲；新增套餐无默认值。

## 横向结论

- **布局**：A 更好（更克制，只有 2 个常驻控件，没有指标卡；左栏即进度）；但 B 的「默认按紧急度排加逾期视图换成权益表」在主次上更对。
- **交互**：A 更好（hover 披露、边填边存、方向滑动、键盘不播动画）；B 的连续性也够，但被常驻按钮、toast、过冲拉低。
- **组件**：B 更全（Tabs、Modal、Tooltip、排序表）；A 更少但更准；两边各有一处手搓图形（A 的状态字形，B 的逾期红条）。
- **拼成一份的这一屏**：
  1. 页头只放「展商」加搜索加新增，下面直接是名单，不放指标卡。
  2. 分区：左栏（或顶部 Tabs，二选一）是「全部 / 钻石 / 金牌 / 银牌 / 展位 / 逾期」，每项一条库自带的 ProgressBar 加 `n / m`；逾期单列红字数。
  3. 默认名单按「下一个截止日」升序，逾期自然在最顶；选中套餐视图后隐藏套餐列。
  4. 「逾期」视图换成权益表，一行一项权益，行尾只放一个推进按钮，点行打开详情并让那一项闪一下。
  5. 点行：右侧浮板从右滑入，不推表格；板内权益按「未交付在前、截止日升序」排。
  6. 推进按钮 hover 或聚焦才出现，改完名单里那一排进度原位变，不弹 toast。
  7. 截止日是日期按钮，点开 Calendar。
  8. 催办是一个输入框，打字后才露出方式、日期、记下。
  9. 上一家 / 下一家写邻居名字，按方向滑。
  10. 新增用右侧浮板：选套餐即时展开权益清单预览，默认当前视图套餐，没有「保存」键；窄屏用底部抽屉，视图用同一组 Tabs。
  11. 色板只用蓝加红，进度和状态字形都用库里的图标和 ProgressBar，不手写 SVG。
