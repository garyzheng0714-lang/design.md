# 展商权益交付 · 过程记录（页面 u）

## 1. 定这一屏

招商运营同学，打开它**推进**每家展商的权益交付（看谁落后 → 推进一项 / 改截止日 / 记催办），做完留在名单上接着看下一家。

功能清单（只做这些）：
1. 每家展商已交付 / 共几项；每个套餐的总进度
2. 一眼找出逾期的权益
3. 名单：公司、套餐、负责人、交付进度、下一个截止日、最近催办；全部显示
4. 按公司名搜
5. 看一家：全部权益（状态、截止日、物料）、催办记录、对接人；上一家 / 下一家
6. 推进一项权益（待提交物料 → 待审核 → 已交付）；改截止日
7. 记一条催办（日期、方式、内容）
8. 新增展商：选套餐自动带权益

共性 → 我们的做法：
- 点一行，详情在右侧打开，名单不走、选中行留底（Square、Attio、Dovetail、Navattic）→ 右侧浮板，非模态，选中行留底。
- 上一个 / 下一个放在详情里（Unify、Twenty）→ 钉在浮板底部，写出邻居名字。
- 搜索贴在表格正上方（Navattic、Square、Midday）→ 标题行右侧，紧贴表头。
- 新建是右上实心按钮（Attio、Airwallex、Slack）→「新增展商」，整页唯一实心。
- 条数只在底栏（Attio、Dovetail、Airtable）→ 表格底栏「28 家」。
- 记备注的输入在时间线顶上、新的在上（Outseta、Unify、Calendly）→ 照做，打字后才露出日期 / 方式 / 记下。
- 分组进度 = 细条 + n/m（Wix、GoDaddy、Linear）→ 左栏每个套餐一条。
- 手机上记录 = 主字 + 一行灰字（Docusign、Evernote）→ 窄屏实体行，状态靠右。

没做（先例有、清单没有）：批量操作、导入导出、排序、上传物料文件、编辑对接人、权益回退一步、删除展商。

## 2.5 骨架（本页规格）

1. **姿态**：名单（总览就是「全部展商」这一视图）。
2. **三版骨架**：
   - A 先例版：左栏视图 + 表格 + 右侧浮板（Attio）。
   - B 形状版：A 的基础上，左栏每个套餐带进度细条；名单「交付进度」画成一排座位，每项权益一格。
   - C 少一层版：页头不再复述总进度（左栏已有）；详情不分标签页，区块往下排。
   - 选 B，借 A 的浮板与上一家 / 下一家，借 C 的不复述、不分标签。
3. **形状**：
   - 套餐进度 = 名字 + 细条 + n / m（权益项数）。
   - 每家交付进度 = 座位条：已交付实心主色、待审核浅主色、待提交物料空心灰框，后跟 n / m。
   - 详情里每项权益用同一个座位字形 + 状态字。
   - 下一个截止日 = 「11月20日」+ 灰字权益名；逾期时红字「逾期 6 天」+ 权益名，是一行里唯一的状态色。
   - 最近催办 = 日期 · 方式（灰）。
   - 催办 = 时间线，新的在上。
4. **区域 → 组件**（HeroUI）：
   - 左栏视图：`ListBox`（单选）+ `ProgressBar` sm；「逾期」单独一项，红色数字。
   - 页头：h1 = 当前视图名；`SearchField` + `Button` primary「新增展商」。
   - 名单：`Table`（secondary，表头吸顶，首列不截断）、套餐 `Chip`（套餐视图里隐藏这一列）、底栏「n 家」。
   - 详情（宽屏）：`Surface` 浮板 ≈ 480，右侧滑入；窄屏 `Drawer` 从底部。
   - 推进：每项权益行尾 `Button` secondary sm「收到物料」/「审核通过」（宽屏指向那一行才出现，触屏常显）。
   - 截止日：文字按钮 → `Popover` + `Calendar`。
   - 催办：`TextArea`；有字后露出 `DatePicker`（默认今天）、`ToggleButtonGroup` 电话 / 微信 / 邮件 / 面谈、`Button`「记下」。
   - 对接人：头部下一块（姓名职位、电话、邮箱、微信）。
   - 上一家 / 下一家：浮板底部，`Button` tertiary 带邻居名；关闭 `CloseButton`，Esc 也关。
   - 窄屏：顶部 `Select` 切视图（带进度）+ 新增图标钮；`SearchField`；实体行。
   - 新增：浮板 / 抽屉进入新增态：`TextField` 公司名、`ToggleButtonGroup` 套餐、`Select` 负责人、对接人字段；权益清单随套餐带出；`Button` primary「添加」。
5. **披露**：
   - 第一层：左栏进度（清单 1）、逾期视图与红字（2）、名单（3）、搜索（4）、新增（8）。
   - 第二层：指向权益行才出现的推进按钮（6）、座位悬停提示权益名。
   - 第三层：详情浮板（5、6、7）。
6. **因果**：
   - 切视图 → 名单交叉淡换（新的从下 8px 落定），标题跟着换；不先空再出。
   - 搜索 → 逐键过滤，不加动画（键盘触发）。
   - 点一行 → 浮板从右滑入，该行留底。
   - 上一家 / 下一家 → 浮板不动，内容按方向滑换；表格选中底跟到那一行。
   - 推进 → 座位填色、状态字换、按钮字换；名单那一行的座位与 n/m 同步；左栏细条长一截。
   - 改截止日 → 日期换字；逾期红字消失或出现；逾期数跟着变。
   - 记催办 → 新一条从 0 高度长出在最上；输入清空并收起选项；名单「最近催办」变成今天。
   - 新增 → 浮板进入新增态，套餐默认当前视图；点「添加」→ 新行在名单最上长出并选中，浮板换成它的详情。

## 6. 用一遍、量一遍

|---|---|---|---|
| 字号 | 12 / 14 / 18 | 12 / 14 / 16 | ≤ 4 ✓ |
| 实心按钮 | 1 | 1 | 每区 ≤ 1、每屏 ≤ 2 ✓ |

§8 的坑逐条：原生日期框（无，Calendar 弹层）· 灰底控件 / 灰底胶囊（无，控件白底带框，套餐改纯字）· toast 复述（无）· 同一份进度画两遍（左栏套餐、名单每家、浮板每项是三个粒度，不重复）· 首列截断（宽屏不截；390 只有超长名截）· 改状态列位置（列序固定，套餐视图里只隐藏「套餐」列）· 每行常显同一图标 / 按钮（推进按钮指向或点那一行才出现）· 键帽（无）· 淡彩底块（无）· 模态遮罩挡名单（宽屏非模态；窄屏底部抽屉有遮罩，是手机的常规写法）· 标签页藏信息（详情不分标签）· 新增弹表单（插一行 + 边填边存）· 切换先空再跳（交叉淡换，新的落定）· 详情只淡入（从右滑入）。

十问：
1. 第一眼最重要的：是。左栏每个套餐的进度和红色逾期数，名单里红字「逾期 N 天」是一行里唯一的状态色。
2. 主操作明确：是。整页唯一实心「新增展商」；推进在那一项权益的行尾。
3. 字号层级：是，3 种（12 / 14 / 18）。
4. 间距统一刻度：基本是。都在 Tailwind 刻度上（gap-1–6、px-2 / 3 / 4 / 6），有 3 处半档：mt-0.5（权益名与灰字行）、gap-1.5（联系方式图标与字），是贴字的微距。
5. 对齐线：是。名单列、浮板里字形 / 名字 / 日期三条竖线；左栏三列网格让细条起止一致。
6. hover / focus / disabled / loading / error：hover、focus 齐（行、权益行、按钮、日期）；没有 disabled 场景（推进到已交付按钮就收走）；没有异步所以没有 loading；error 只有「搜不到」的空态。

8. 窄屏：是。视图收进下拉、实体行、底部抽屉。
9. 长文本 / 空 / 极端：长公司名、长文件名（换行不截）、空搜索都看过；不会炸。
10. 为好看牺牲可用性：否。推进按钮宽屏指向才出现，是为了少，但键盘聚焦进那一行也会出现。

和先例比哪一处不如它：Attio 的浮板打开时名单仍然露出最重要的列；我们的浮板盖住了「下一个截止日」和「最近催办」，开着详情时看不到别家逾期。另外 Unify 的上一个 / 下一个在面板头部，一眼就看得到，我们放在底部。

## 7. 盲评（自评，没有另起智能体）

底线：不挤 过 · 组件用得对用得足 过（日期用弹层日历、详情用浮层、进度用座位和细条）· 有因果有连续 过（浮板滑入、行留底、新行从 0 高长出、催办从时间线顶上长出；负载高时新行晚约 0.6s 出现）· 渐进披露 过 · 不懵 过 · 没有低级视觉错 过 · 没有 AI 味装饰 过 · 不套模板 过（左栏就是套餐进度，名单列是用户原表的列）。

打分：第一次用会不会懵 7（座位字形要看一次才懂，没有图例）· 像成熟产品 7 · 少而精 8 · 布局 7（浮板盖住截止日列）· 交互连续与披露 7。总分 72。

最该改的 3 处：
1. 浮板开着时看不到别家的「下一个截止日」：要么浮板变窄、名单收掉「最近催办」，要么把截止日列挪到进度前面（会改用户原表的列序，没做）。
2. 新增的那一行在负载高时晚出现（名单是延后渲染的大块）：生产构建下会快很多，开发模式里能看到停顿。
3. 刚新增的展商立刻「逾期 1 天」（模板里会刊名录 11 月 5 日截止），数据上没错，但新人第一眼会以为出错；可以在插入时把已过的截止日标出来让人当场改。

第一轮自评就到 72，底线全过，没有再改第二轮。第一轮里改过的：窄屏推进按钮不再给每行留空（文件名从挤成 3 行恢复正常）。
