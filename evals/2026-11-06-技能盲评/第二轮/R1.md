## 第四部分：取长补短

### A 最值得借的 3 处
1. **左栏就是视图**（scopes.tsx `ScopeNav`）：每个套餐一行，名字 + 细进度条 + 已交付 / 共几项，「逾期」单独隔开一组。功能 1 和 2 直接变成导航，h1 跟着视图变；选中某个套餐后表格自动去掉「套餐」列（roster.tsx `showPkg`）。不用指标卡，也不重复。
2. **新增 = 表顶插一行 + 面板里边填边存**（page.tsx `startCreate`，create.tsx）：那一行从 0 高长出来，同时打开详情，光标在公司名；套餐默认取当前视图，用平铺的 ToggleButtonGroup；换套餐，权益清单立刻跟着换。不弹表单，前因后果连得上。
3. **详情浮板不压表格，换家有方向**（panel.tsx）：`absolute bottom-2 right-2 rounded-2xl` 浮在主卡里，圆角同心；底部写出邻居的名字「‹ 山岚饮品 / 北纬茶研 ›」，换家时按方向左右滑；推进按钮指向才出现，原位换字；催办输入框打字后才长出方式、日期和「记下」。

### A 最该避免的 3 处
1. 视图切换时新旧内容叠在一起：AnimatePresence 没写 `mode="wait"`（page.tsx:238），S2-90 有残影。
2. 还没起名的草稿就算进了总数：S9-90 左栏 125→128、逾期 6→7、「29 家」；草稿的公司输入框还因为 `pr-10` 右缘不齐（create.tsx:19）。
3. 自造点阵和其他细节：每家的进度是手画的点阵，空环淡到几乎看不清（glyph.tsx）；默认不按截止日排；关闭钮带灰圆底；常驻「28 家」计数行；窄屏把套餐进度收进了 Select。

### B 最值得借的 3 处
1. **逾期按权益一行，行尾直接推进**（Roster.tsx `OverdueTable`，S2-700）。表格默认按「下一个截止」排（page.tsx:46），每天要处理的事都在最上面。
2. **套餐用 Tabs 同时当筛选和总进度，宽窄屏是同一个控件**：手机上横向滑动，「逾期」挪到第二位（page.tsx:35），选中指示块会滑过去，换视图有连续感。
3. **详情里的细节**：截止日按钮直接写「逾期 6 天 / 还剩 7 天 / 11月20日」，点开就是日历（DuePicker.tsx）；已交付的沉到底；负责人写「我负责」；新增时选了套餐才展开带出的权益清单（NewExhibitor.tsx），让人在提交前看到「选了会怎样」；推进可以撤销。

### B 最该避免的 3 处
1. 用宽度动画推开详情（page.tsx:297）：表格和套餐砖逐帧重排，最后一列被截断。
2. 装饰和多色：每行的套餐胶囊、6 根红短杠、橙 / 绿 / 琥珀色状态、详情里的灰卡套灰卡、灰圆图标底、「/」和 J / K 键帽、复述型 Toast。
3. 新增用居中 Modal，套餐还没有默认值（NewExhibitor.tsx:43）；砖的指示块不同心，滑动途中盖住邻砖。

## 横向结论

布局 A 更好（左栏视图 + 浮板不压表，留白和主次更稳）；交互 A 更好（有方向、插行、指向才出现，因果连得上）；组件选择各有长处，B 的想法更多（逾期专表、可排序、相对日期、撤销），但 B 的表现层做加法太重。

把两份的长处拼成一份，这一屏应该是：
1. 左栏（照 A）：「全部 / 钻石 / 金牌 / 银牌 / 展位」每行名字 + 细 ProgressBar + 已交付 / 共几项（带单位「项」），下方隔开一组「逾期」；窄屏换成 B 那种可以横滑的同形分段砖，不收进下拉。
2. 主区表格：默认按下一个截止日排（照 B），选中某个套餐时去掉套餐列（照 A）；进度用 ProgressBar 加「3/6 项」，不用点阵，也不用胶囊；没有计数行。
3. 逾期视图：按权益一行（照 B），行尾的推进按钮指向才出现（照 A）。
4. 详情：浮在表上的面板，不推表格（照 A）；头部 ⌃ ⌄ 改成写邻居名，按方向滑（照 A）；截止日用相对日期 DuePicker（照 B）；推进在原位换字，撤销留在原位（不用 Toast）。
5. 催办：输入框常驻，打字后长出方式、日期和「记下」（照 A）。
6. 新增：表顶插一行，面板里直接填（照 A）；选了套餐就展开权益清单（照 B）；起名之前不算进任何总数。
7. 动效：视图切换用 `mode="wait"` 并跟着列表顺序带方向，指示块要同心并压在内容下面，弹簧 bounce ≤ 0.15，键盘操作零动画。
