# 参赛规则

你在做一个题目。题目在 `/tmp/skill-bench/round3/brief.md`，先读完。

## 技术栈（固定）

- 只写一个页面：`/tmp/skill-bench/hero/src/pages/<你的页面id>.tsx`（默认导出页面组件，已有空占位，先 Read 再覆盖）。要拆文件就放 `/tmp/skill-bench/hero/src/pages/<你的页面id>/` 下面再 import；方案图放 `/tmp/skill-bench/hero/src/pages/<你的页面id>-design/`。别的目录一个字都不改（数据文件只读）。
- 组件只用 HeroUI v3：`import { … } from "@heroui/react"`（已装 3.2.7）。样式用 Tailwind v4 加 HeroUI 自己的主题变量；主题已经装好（`src/app.css`），不改主题。
- 图标只用 `lucide-react`；动画可以用 HeroUI 自带的，也可以用 `motion/react`（已装）。不装任何新依赖。
- 交互都要真的能用（本地 React 状态），不许有点了没反应的按钮。
- 代码注释里不要提你用的设计方法、技能或这次测试的名字（评审是盲评）。

## 怎么看自己的页面

- 开发服务器已经在跑：`http://127.0.0.1:5411/<你的页面id>`（关了热更新，改完重新截图就是新的）。不要自己再起服务器，也不要关它。
- 截图、探针用设计技能自带的脚本（技能目录下 `scripts/shoot.mjs`、`scripts/probe.mjs`，地址写 `http://127.0.0.1:5411/<你的页面id>`）；截图放 `/tmp/skill-bench/out/<你的页面id>/shots/`。用 Read 打开 png 看。
- 类型检查：`cd /tmp/skill-bench/hero && node_modules/.bin/tsc --noEmit -p .`
- 另一位参赛者也在用同一台开发服务器，别动它的文件。

## 交付三样

1. 页面文件。
2. `/tmp/skill-bench/out/<你的页面id>/states.json`：用你页面里的选择器或看得见的文字，实现下面这些操作场景（格式见 `shoot.mjs` 文件头；每个状态从刚打开的页面开始）。场景名照写：
   - `S1-总进度`：看到每个套餐的总进度要做的操作（首屏就能看到就写空步骤），frames [700]
   - `S2-逾期`：找出所有逾期的权益，frames [90, 700]
   - `S3-切套餐`：只看「金牌」的展商，frames [90, 700]
   - `S4-开详情`：打开「青屿饮品」，frames [90, 700]
   - `S5-推进`：把青屿饮品的「会刊整页广告」往下推一步，frames [90, 700]
   - `S6-改截止日`：打开青屿饮品「会刊整页广告」的截止日控件，frames [500]
   - `S7-记催办`：在青屿饮品开始记一条催办并输入「电话催物料，对方周五前发终稿」，frames [700]
   - `S8-直接推进`：不开详情，在名单里把「小满酸奶」的下一项权益往下推一步（做不到就写空步骤，并在 NOTES 里写为什么），frames [90, 700]
   - `S9-新增`：开始新增一家展商，frames [90, 700]
   - `S10-窄屏详情`：width 390，打开任意一家展商，frames [90, 700]
   - `S11-搜索`：搜「禾川」，frames [700]
   - `S12-翻页`：翻到名单下一页（名单一屏放得下、不需要翻页就写空步骤，并在 NOTES 里写为什么），frames [90, 700]
   做不到的场景也写上，步骤留空，并在 NOTES 里写为什么。
3. `/tmp/skill-bench/out/<你的页面id>/NOTES.md`（≤ 30 行）：你做了哪几步、布局决定用 5 行说清（分区、主次、每块用了哪个组件、渐进披露、动效）。

最后跑一遍 `shoot.mjs --states …` 全部场景，确认每个场景都拍出来、页面没有报错，再交。
